# 产品定义与功能契约 v5（正式命题版）

> 命题：**AI + 华为PC营销软文智能体**（拓浙AI生态 × 华为中国区）
> 评分满分100：业务场景理解20 / 产品事实准确性20 / 图文生成与图片引用15 / 平台适配15 / 自研Agent与提示词15 / 功能完成度10 / 合规安全5

## 一、产品定位

自研 Agent 完成"**理解需求 → 查找资料 → 选择图片 → 生成内容 → 核验结果**"闭环。
**ima 只作华为产品事实和图片素材来源**；自研 Agent 负责场景理解、平台策略、提示词设计、图文编排、事实核验、合规检查。

## 二、8 个功能板块（赛题最低要求，缺一不可）

| 板块 | 最低要求 | 现场检查方式 |
|---|---|---|
| 1 账号与知识库 | 识别当前账号；找到"任德耀新建华为PC知识库"；不展示完整密钥 | 核查库名、连接状态、接口返回 |
| 2 任务输入 | 输入产品/人群/场景/渠道；信息不足时追问 | 评委给不完整任务 |
| 3 知识与图片检索 | 调 ima OpenAPI 检索资料与图片，保留来源记录 | 现场换产品、抽查图片来源 |
| 4 场景与平台策略 | 识别人群/场景/目标/平台，形成可解释策略 | 换场景或平台比较差异 |
| 5 图文软文生成 | 标题/正文/行动引导/图片引用和插入位置 | 随机指定平台 |
| 6 事实核验 | 逐项检查产品事实，无依据内容删除或标记 | 设置易混淆型号 |
| 7 合规检查 | 识别绝对化用语、虚假承诺、价格误导、无依据对比、竞品贬低 | 统一测试样本 |
| 8 修改与导出 | 据临时要求重新生成；支持复制/导出 | 删减、换渠道、替换卖点 |

## 三、ima OpenAPI 调用链（硬性）

**✅ 已实测通过（2026-10-18 14:05，test_ima.py 输出）：**
- 知识库名：任德耀新建华为PC知识库（共享，43成员）
- kb_id：`rlFXVWSgzzyllb8nKnATSvMBxVJGQ1-CwarZdVMKhMI=`（内容1519项；注意返回字段为 kb_id/kb_name）
- 根目录 media_id：`folder_7517317118306152`，parent_folder_id：`7514565705233223`
- API 返回结构：`{code, msg, data{...}, request_id}`，data 内含 info_list / knowledge_list

```
A. search_knowledge_base  {"query":"任德耀新建华为PC知识库"} → 取 data.info_list[0].kb_id
B. get_knowledge_list     {"knowledge_base_id":"<kb_id>"}     → 搜索为空时回退浏览目录
C. search_knowledge       按"型号 + 任务要求"搜索资料
D. get_media_info         取命中资料原文或访问链接
```

- 官方 skill 包已下载解压：`ima-skill-pkg/ima-skill/`，API 文档在 `knowledge-base/references/api.md`
- **已确认的接口规格（直接用 Python requests 实现，不需要 node）**：
  - Base URL：`https://ima.qq.com/openapi/wiki/v1`
  - 全部 HTTP POST + JSON body
  - Header：`ima-openapi-clientid` / `ima-openapi-apikey` / `Content-Type: application/json`
  - `search_knowledge_base`：query/cursor/limit → `info_list[].id` 即 kb_id
  - `get_knowledge_list`：knowledge_base_id/cursor/limit → 浏览目录（搜索为空时回退）
  - `search_knowledge`：按型号+任务搜索 → media_id/title/highlight_content
  - `get_media_info`：media_id → 原文内容或 url_info（图片素材访问链接）
- 凭证从 https://ima.qq.com/agent-interface 获取，**必须先扫码加入共享知识库，且用同一账号**
- 凭证绝不能出现在 GitHub / 魔搭 / 说明书 / 截图 / 视频里，走创空间密文变量
