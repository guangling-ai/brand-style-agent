# 演示用测试数据（赛前彩排 & 现场兜底用）

> 万一现场网络/API出问题，就用这套数据演示。也可赛前自己在家先跑一遍彩排。

## 测试案例1：新消费品牌（推荐演示用）

- 品牌名：桃气研究所
- 产品卖点：0糖0脂白桃气泡水，添加真实桃汁，330ml便携装，便利店有售
- 历史文案样本（粘贴进输入框）：

```
样本1：午后的困意，交给一颗桃子解决。🍑 桃气研究所，0糖也好喝。
样本2：便利店的冷气很足，桃子的香气更足。下班路上，顺手带走一罐夏天。
样本3：不加糖的气泡水很多，加真桃汁的只有我们。喝过的人都说：像在咬一颗脆桃。
```

- 预期效果：文风指纹应识别出"短句、画面感、轻emoji、拟人化、年轻女性向"

## 测试案例2：B端企业服务（贴合"企业真实业务问题"调性）

- 品牌名：数链云
- 产品卖点：中小企业财务自动记账SaaS，发票拍照即入账，月结从3天缩到2小时
- 历史文案样本：

```
样本1：财务报表不该是老板的天书。数链云，让每一分钱都看得懂。
样本2：会计加班做账的时代结束了。发票拍一下，账就记好了。
样本3：3000家中小企业的共同选择：月结从3天，到2小时。
```
