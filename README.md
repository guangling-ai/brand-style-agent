# AI+华为PC营销软文智能体

> 拓浙AI生态 × 浙客松 · AI+X破界黑客松 **华为·产业进阶赛道** 参赛作品
> 自研 Agent 完成"理解需求 → 检索资料 → 选择图片 → 生成内容 → 核验结果"的营销软文生产闭环。

## 一、产品简介

面向华为 PC 门店导购与内容运营场景：输入**产品型号、目标人群、使用场景、发布平台**，Agent 自动完成：

1. **场景解析**：抽取人群 / 场景 / 购买阶段 / 痛点 / 内容目标，信息不足时主动追问
2. **平台策略**：公众号 / 小红书 / 门店朋友圈 / 门店海报四套差异化写作规范（结构、语气、图片数量、行动引导均不同）
3. **知识与图片检索**：调用 **ima OpenAPI** 检索"任德耀新建华为PC知识库"（1519 项官方资料），产品事实与图片**全部来自知识库**并保留来源记录
4. **图文软文生成**：标题 / 导语 / 正文 / 行动引导 / 配图方案（含图片来源、插入位置、图片说明）
5. **事实核验 + 合规检查**：逐条比对知识库依据；拦截绝对化宣传、虚假承诺、价格误导、无依据对比、竞品贬低；无依据内容拒绝生成或标记"待确认"
6. **修改与导出**：支持换平台重新生成、一键复制、导出 Markdown

输出严格遵循赛题四段式格式：**一、场景判断｜二、知识库依据｜三、图文软文｜四、核验结果**。

## 二、架构设计（RAG + 规则引擎 + 多步核验）

```
任务输入 → 场景解析 → 平台策略 → ima资料/图片检索 → 事实点提取
        → 图文编排 → LLM生成 → 事实/图片核验 → 合规检查 → 四段式输出/导出
```

- **系统提示词**按赛题第 5 页（三）要求的 7 个模块设计（角色与任务 / 场景理解 / 平台规则 / 知识库约束 / 图片规则 / 生成要求 / 核验与合规），内置为 `app.py` 中的 `SYSTEM_PROMPT` 常量，与作品说明书口径一致
- **ima 客户端**：纯 Python `requests` 实现（base `https://ima.qq.com/openapi/wiki/v1`，Header 鉴权），实现 `search_knowledge_base → search_knowledge → get_knowledge_list 回退 → get_media_info` 四接口链路；kb_id 界面脱敏展示
- **双路 LLM**：主线魔搭 API-Inference（Qwen3.5），备用 DeepSeek；**全部失败时进入离线降级模式**，读取本地知识库快照 + 预置演示数据，保证演示永不白屏
- **本地知识库快照**（`华为PC知识库/`，314 项）用作检索索引与离线兜底

## 三、运行方法

```bash
# 1. 安装依赖（Python 3.10+）
pip install -r requirements.txt

# 2. 配置凭证：复制 .env.example 为 .env 并填写
#    IMA_OPENAPI_CLIENTID / IMA_OPENAPI_APIKEY   （ima 接口凭证，https://ima.qq.com/agent-interface 获取）
#    MODELSCOPE_API_KEY / LLM_MODEL              （魔搭 API-Inference，可选）
#    LLM_API_KEY                                 （DeepSeek 备用，可选）
#    ⚠️ .env 含密钥，严禁上传仓库；凭证须使用环境变量或密文管理

# 3. 启动
python app.py
# 浏览器打开 http://127.0.0.1:7860
```

无凭证状态下应用也可启动并演示（离线降级模式，输出预置演示数据并明确标注）。

## 四、魔搭创空间部署

- 依赖：`requirements.txt`（gradio / openai / requests / python-dotenv，版本锁定）
- 密钥通过创空间**密文变量**注入（`IMA_OPENAPI_CLIENTID`、`IMA_OPENAPI_APIKEY`、`MODELSCOPE_API_KEY`），明文变量配置 `LLM_MODEL`
- 启动监听 `0.0.0.0:7860`

## 五、安全说明

- 所有凭证走环境变量 / `.env`（已排除在仓库外） / 创空间密文变量
- 界面上 kb_id 等标识已脱敏显示
- 仓库、截图、演示视频中均不包含完整密钥

## 六、已知限制

- 生成质量依赖知识库覆盖范围：知识库未收录的型号/价格/补贴信息会触发"无依据"拦截而非生成
- 免费算力下首次生成需等待数秒（LLM 推理 + ima 检索）
- 离线降级模式的结果为预置演示数据，仅用于保底演示
